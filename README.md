# BLUNT - Site de Moda Urbana

Um site minimalista e moderno de e-commerce de roupas, inspirado no estilo da marca BLUNT.

## 📋 Características

✅ Design minimalista e moderno
✅ Navbar com navegação fluida
✅ Hero section impactante
✅ Grid de coleções com hover effects
✅ Produtos em destaque com badges
✅ Seção sobre a marca
✅ Newsletter para inscrição
✅ Footer completo
✅ Totalmente responsivo (mobile, tablet, desktop)
✅ Animações suaves e transições

## 🚀 Como Usar

1. Clone ou baixe o repositório
2. Abra o arquivo `index.html` no navegador
3. Customize as imagens, cores e conteúdo conforme necessário

## 📁 Estrutura de Arquivos

## 🎨 Personalização

### Cores Principais
- **Preto (#000)**: Botões e destaque
- **Branco (#fff)**: Fundo
- **Cinza (#f5f5f5, #f9f9f9)**: Fundo secundário
- **Cinza escuro (#1a1a1a)**: Footer

### Fontes
- **Montserrat** (Google Fonts) - Para todos os textos

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3 (Flexbox, Grid)
- JavaScript Vanilla
- Google Fonts
- Placeholders de imagem

## 💡 Sugestões de Melhoria

1. **Substituir imagens**: Trocar placeholders por imagens reais
2. **Backend**: Implementar sistema de carrinho com persistência
3. **Autenticação**: Adicionar login/registro de usuários
4. **Pagamento**: Integrar gateway de pagamento
5. **Dashboard Admin**: Painel para gerenciar produtos
6. **Blog**: Adicionar seção de artigos sobre moda

## 📱 Responsividade

O site é totalmente responsivo para:
- Desktop (1200px+)
- Tablet (768px - 1199px)
- Mobile (até 480px)
